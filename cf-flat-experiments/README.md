# Design at CustomerFirst

This is where the CustomerFirst design team keeps its prototypes, service maps and other design artefacts, and the rules and Claude skills we use to build them.

- [`CLAUDE.md`](CLAUDE.md): how we build. Written by the team, and open to change.
- [`components.html`](components.html): the GOV.UK components prototypes are built from.
- [`DESIGN-template.md`](DESIGN-template.md): a starting point for a project's own design guidance.
- [`.claude/skills/`](.claude/skills): skills Claude uses when you work here, to build prototypes and review them.
- One folder per project: [Drivers Medical](drivers-medical/) and [NHS App](nhs-app/).

When you open this repo in Claude, it offers to install the [government communication skills](https://github.com/strachcity/gov-communication-skills) for letters, emails, texts and what they reveal about a person. Say yes.

## Working in this repo

1. Clone this repo in GitHub Desktop.
2. In the Claude desktop app, start a Code session in the repo folder.
3. Build in your project's folder. Ask Claude to review it before you show anyone.
4. In GitHub Desktop, check your changes, commit them with a short summary, and push.

To add a project, make a folder for it and add it to the list above.

If a rule got in your way, or you've made a new kind of thing more than once, change `CLAUDE.md` or add a skill, and tell the team.
